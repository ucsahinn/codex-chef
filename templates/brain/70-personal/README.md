# Personal

## Türkçe

Yalnız açıkça onaylanmış kişisel bağlamı sakla. Sağlık, finans, hukuk, kimlik ve ilişki bilgilerini hassas say; varsayılan olarak barındırılan dizinlerden çıkar.

## English

Store only explicitly approved personal context. Treat health, finance, legal, identity, and relationship information as sensitive and exclude it from hosted indexing by default.
