# Goals

## Türkçe

Gözden geçirilmiş hedefleri, başarı ölçütlerini, zaman ufkunu ve durumu sakla. Görev yürütme durumunu ilgili projede veya Control içinde tut.

## English

Store reviewed goals, success criteria, time horizons, and status. Keep task execution state in the relevant project or Control.
