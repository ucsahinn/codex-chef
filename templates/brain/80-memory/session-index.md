# Session Index

## Türkçe

Yalnız bir kararı, proje durumunu veya sonraki eylemi değiştiren anlamlı oturum özetlerini kaydet. Kayıtları kısa tut ve kalıcı notlara bağla.

## English

Record only meaningful session summaries that changed a decision, project state, or next action. Keep entries short and link to durable notes.
