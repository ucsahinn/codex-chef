# User Profile

## Türkçe

Yalnız kullanıcının açıkça saklamak istediği kararlı ve yararlı tercihleri ekle. Hassas özellikleri çıkarımla doldurma.

## English

Add only stable, useful preferences that the user explicitly wants to preserve. Do not infer sensitive attributes.
