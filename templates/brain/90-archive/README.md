# Archive

## Türkçe

Yalnız açık onayla arşivle. Arşivleme bulunabilirliği değiştirir; kaynağı silmemeli veya kullanıcı bilgisini sessizce yok etmemelidir.

## English

Archive only with explicit approval. Archiving changes discoverability but must not erase provenance or silently delete user knowledge.
